# Kaspion Web handoff

The complete handoff is at **[../HANDOFF.md](../HANDOFF.md)** in the repository
root. It covers the goal, completed work, validation, remaining tasks, setup
commands, and continuing with Codex CLI.

From this directory, the quick start is:

```bash
node start-demo.mjs
```

Requires Node.js 22.22.2 or newer. The launcher starts a local synthetic demo at
`http://localhost:3002`, with live bank scraping disabled.

Suggested first Codex CLI prompt:

> Read ../HANDOFF.md, README.md, and ARCHITECTURE.md. Help me run the existing
> multi-user Hebrew Kaspion Web demo. Preserve user data and leave live scraping
> disabled until I explicitly request an authorized bank test.
